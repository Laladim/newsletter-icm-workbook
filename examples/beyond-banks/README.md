# Beyond Banks sanitized example

This example shows how discovery answers become a publication brief and six
profile contracts.

It intentionally excludes account identifiers, credentials, local machine
paths, private sources, production content, unpublished strategy, edition
records, and performance data. It does not reproduce or replace any private
production workspace.

Read:

1. `publications/beyond-banks/publication-brief.md`
2. `answer-to-file-crosswalk.md`
3. the six generated files under `publications/beyond-banks/`

The example is optional. A new publication must be generated from its own
interview and may not inherit this audience, topic, source, voice, visual, or
delivery profile.
