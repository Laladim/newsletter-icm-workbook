# Capability bindings for Beyond Banks

This sanitized profile uses explicit manual procedures and claims no installed
private tool.

| Capability | Canonical binding | Trigger | Output proof | Required? |
|---|---|---|---|---|
| candidate discovery | manual: gather candidate material from approved public source classes | Stage 02 after intake passes | candidate set with opened source locations and checks | yes |
| research and source verification | manual: open sources and build the claim-level evidence ledger | Stage 03 for selected candidates | research packet and source ledger | yes |
| editorial judgment | manual: apply the approved reader promise and lead criteria | Stage 04 after evidence passes | editorial plan and routing receipt | yes |
| newsletter writing | manual: draft local Markdown from the verified editorial plan | Stage 05 after routing passes | complete Markdown draft | yes |
| factual and risk review | manual: compare every material claim with the source ledger and risk rules | Stage 06 on the complete draft | quality report and corrected artifact hash | yes |
| visual production | none: visuals are optional in this sanitized profile | Stage 05 visual decision | visual brief records not applicable or inspected optional visual | no |
| subject and packaging | manual: assemble one consistent local delivery package | Stage 07 after quality passes | package manifest and immutable local package | yes |
| delivery adapter | manual: create and inspect the local Markdown review surface | Stage 08 in shadow mode | local artifact pointer and match receipt | yes |
| analytics and records | none: no post-publish data is included in the sanitized example | Stage 09 | stage remains unopened | no |
