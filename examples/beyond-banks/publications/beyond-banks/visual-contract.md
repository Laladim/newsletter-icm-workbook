# Visual contract for Beyond Banks

Source: the approved `publication-brief.md`.

## Requirement

Visuals are optional in this sanitized profile. The edition can pass with no
visual when text alone serves the reader.

## Identity and accessibility

No brand system is included. Any optional visual must use readable contrast,
accurate alt text, and no unsupported claim or misleading decorative label.

## Concept selection

Use a visual only when it explains the edition's subject or reader consequence
more clearly than text. The profile binds no generator.

## Inspection

If a visual is added later, a human must inspect its relevance, accuracy,
legibility, accessibility, crop, and final-surface appearance before approval.
