# 07_package output contract

Create `output/package-manifest.md` with:

```text
# Delivery package manifest

- Edition ID:
- Verified draft pointer and identifier:
- Subject:
- Subject evidence card and cohort:
- Preview text:
- Combined inbox simulation:
- In-body title and subtitle:
- Hero image pointer:
- Hero alt text:
- Body artifact:
- Sources count and citation check:
- Recurring modules:
- Optional supporting media and selection reason:
- Links checked:
- Audience or segment:
- Tags and metadata:
- Final review surface:
- Package hash or immutable identifier:
- Package verification result:
```

Put the immutable local package in `output/delivery-package/`, or record its
exact location and identifier in `output/package-pointer.md` when the
publication contract requires an external canonical package. The package must
include one evidence-supported subject and preview pair, not a routine menu of
choices. Verify the complete package, then create `output/stage-receipt.md`
using `_shared/approval-contract.md` when the exit gate passes.
