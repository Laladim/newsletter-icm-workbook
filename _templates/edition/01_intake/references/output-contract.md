# 01_intake output contract

Create `output/assignment.md` with:

```text
# Edition assignment

- Edition ID:
- Publication ID:
- Edition date:
- Mode:
- Request type: new edition | revision | replay | post-publish
- Exact request:
- Supplied starting point: rows | topic | keyword | analytics | source | none
- Supplied material and locations:
- Intended reader outcome:
- Required output format and home:
- Final review surface:
- Editorial-routing approver:
- Final-review approver:
- Schedule/send/publish authority:
- Constraints and exclusions:
- Missing input:
- Approved deviation: none | describe
```

Copy facts from the publication profile and the user's exact request. Do not
infer a different publication, audience, account, output home, or authority.
After the assignment exit gate passes, create `output/stage-receipt.md` using
`_shared/approval-contract.md` and continue automatically.
