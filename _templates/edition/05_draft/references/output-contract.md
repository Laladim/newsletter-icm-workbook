# 05_draft output contract

Create the full reader-facing draft as `output/draft-artifact.<extension>`,
where the publication profile defines the extension. A partial outline is not
the draft artifact.

Create `output/visual-brief.md` with:

```text
# Visual brief

- Exact in-body H2:
- Visible title entity:
- Article thesis:
- Operator consequence:
- Primary visual metaphor:
- Composition:
- Story-specific objects:
- Brand and palette rules:
- Repetition variables changed:
- Generator or production route:
- Output pointer:
- Dimensions and crop:
- Visual inspection evidence:
- Result: pass | revise
```

If the full draft or visual must remain outside the edition folder, create
`output/artifact-pointer.md` with its exact path or URL, hash or immutable
identifier, observed-at time, and inspection evidence.

The draft must follow the publication's configured structure, evidence,
citation, style, recurring-section, and visual requirements. In shadow mode,
all artifacts stay inside this edition. Inspect and revise the complete draft
and required visual, then create `output/stage-receipt.md` using
`_shared/approval-contract.md` when the exit gate passes.
